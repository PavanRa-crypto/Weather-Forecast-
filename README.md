# Weather Forecast

A simple and interactive web-based weather forecasting application built with HTML, JavaScript, and CSS.

## 📋 Overview

This project provides real-time weather information and forecasts for any location. The application features an intuitive user interface for checking current weather conditions and upcoming forecasts.

## 🛠️ Technologies Used

- **HTML** (72.4%) - Structure and markup
- **JavaScript** (24.9%) - Dynamic functionality and API interactions
- **CSS** (2.7%) - Styling and responsive design

## 🎯 Features

- Real-time weather data
- Weather forecasts
- Location-based weather search
- Responsive and user-friendly interface
- Clean and modern UI design

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for weather data

### Installation

1. Clone the repository:
```bash
git clone https://github.com/PavanRa-crypto/Weather-Forecast-.git
```

2. Navigate to the project directory:
```bash
cd Weather-Forecast-
```

3. Open the HTML file in your web browser:
```bash
open index.html
# or simply double-click the index.html file
```

## 💻 Usage

1. Launch the application in your web browser
2. Enter a location or allow the app to detect your current location
3. View current weather conditions and forecasts
4. Check temperature, humidity, wind speed, and other weather details

## 🔌 API Integration

This project integrates with a weather API to fetch real-time weather data. Make sure you have a valid API key configured if required.
